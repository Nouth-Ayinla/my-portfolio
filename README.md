# Oluwaferanmi Ayinla Portfolio

A responsive frontend developer portfolio built with Next.js, React, and Tailwind CSS. It presents Oluwaferanmi's profile, skills, featured projects, and contact information in a single-page experience.

## Tech Stack

- Next.js 16 with the App Router
- React 18
- Tailwind CSS 3
- Framer Motion
- Lucide React and React Icons

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

```bash
npm run dev    # Start the local development server
npm run build  # Create an optimized production build
npm run start  # Run the production build
npm run lint   # Check the source files with ESLint
```

## Project Structure

```text
public/              Static images, project screenshots, and resume
src/app/             Next.js App Router entry points and metadata
src/components/      Portfolio sections and navigation
src/App.jsx          Interactive single-page application shell
src/styles.css       Tailwind directives and shared styles
```

## Production

Create and run a production build locally:

```bash
npm run build
npm run start
```

The site can be deployed to any platform that supports Next.js applications.
